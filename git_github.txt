1. Git : is a version control system 
2. github/gitlab/gitbucket : platform that uses git  
3. PAT(personal access token) : used to connect to github from local 

# Commands:
1. git --version : to see version
2. git init : to initialise an empty git repo
3. git status : to show status
3. git add file-name : to stage 
4. git rm --cached file-name : to unstage
5. git commit -m "message" : to go to tracked state
6. git restore file-name : to restore a deleted file
7. git remote add origin (link) : to link remote repo
8. git branch -M master : to branch to master
9. git push -u origin master : to push to master
10. git remote -v : to check the remote link
11. fork : to clone github to github (can use sync fork to sync)
12. clone : to clone github to local
13. git remote set-url : to set url for origin using PAT url
14. git pull origin master : to sync with github changes
15. git branch : to check branches
16. git branch (name) : to make new branch
17. git switch dev OR git checkout dev : to switch branch
18. git log --oneline : shows history 
19. git fetch : to get curr
